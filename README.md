## Local preview

Open any HTML file directly in a browser, or serve the directory:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080.

## Deployment

This site is deployed on **Vercel** with auto-deploys from the `main` branch. The `vercel.json` config enables clean URLs (e.g. `/about` instead of `/about.html`).
